# The Digital Detective 🔍

## About

This repository is for my Diwali Independent Learning Assignment, *The Digital Detective*.

Through this assignment, I'll be exploring different things about computers, such as how they work, how to use the Terminal, how operating systems manage files and programs, and how computers represent data. I'll also be practising Python, Git, GitHub and basic networking.

## What I'll Be Learning

- Computer hardware and software
- IPOS (Input, Processing, Output and Storage)
- Basic Terminal commands
- File and folder management
- Operating systems and processes
- Compilers and interpreters
- Python programming
- Binary, decimal and hexadecimal numbers
- ASCII and UTF-8
- Git commands, branches and Pull Requests
- Computer networks and DNS

## Python Number Converter

In Mission 5, I'll be creating a small Python program that converts decimal numbers into binary and hexadecimal.

To run the program:

```bash
cd mission-05-numbers-data
python3 number_converter.py
```
